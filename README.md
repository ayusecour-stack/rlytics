# RLytics

**Les rangs de tout le lobby Rocket League, sans quitter ta partie.**

RLytics affiche le tracker de chaque joueur de ta partie Rocket League (PC) et met leur rang, leur division et leur MMR directement dans ton tableau des scores quand tu tiens Tab.

- Le tracker de chaque joueur : 2, 4 ou 6 carrés selon le mode, un clic pour l'avoir en grand
- Les rangs dans le tableau des scores (logo + division + MMR)
- Compatible Easy Anti-Cheat : RLytics lit la Stats API officielle du jeu, rien n'est injecté
- Historique des parties, thèmes de couleurs et thèmes anime
- Mises à jour automatiques

## Télécharger

👉 **[Télécharger RLytics pour Windows](https://github.com/ayusecour-stack/rlytics/releases/latest/download/RLytics-Setup.exe)** · [Site de présentation](https://ayusecour-stack.github.io/rlytics/)

Windows peut afficher « Windows a protégé votre ordinateur » (pas de signature payante) : clique sur « Informations complémentaires » puis « Exécuter quand même ».
